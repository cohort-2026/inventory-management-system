# Inventory Management System
 
Three-tier inventory management app.
 
## Stack
- Frontend: React + TypeScript (Vite)
- Backend: Express + TypeScript
- Database: Supabase (PostgreSQL)
 
## Getting Started
 
### Frontend
```
cd frontend
npm run dev
```
 
### Backend
```
cd backend
npm run dev
```
 
Fill in the .env file with your Supabase project URL and keys before running.
